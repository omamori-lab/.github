# omamori

Open-source tools for AI safety.

## Projects

### AI control

- [langchain-sync-monitors](https://github.com/omamori-lab/langchain-sync-monitors):
  a monitor for every step a LangChain agent or Deep Agent proposes, and a
  control protocol that decides what runs.
- [hyoshigi](https://github.com/omamori-lab/hyoshigi): a framework-free core
  for monitors over an agent's trajectory, in design.

## The name

An omamori (御守) is a protective amulet from a Japanese shrine or temple,
carried on the person
([Encyclopedia of Shinto, Kokugakuin University](https://d-museum.kokugakuin.ac.jp/eos/detail/?id=9633)).
We use it as a metaphor for tools built to protect people from harm caused by
AI systems. We have no connection to any shrine or religious practice, and we
mean the name with deep respect for the tradition it comes from.
[More on the name](https://github.com/omamori-lab/.github/blob/main/name.md).
